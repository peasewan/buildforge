# BuildForge

BuildForge is a visual WoW Forever Paladin talent planner for Holy, Protection, and Retribution builds.

> **Beta talent data.** The planner currently contains all 52 Paladin talent nodes from WoW Forever Beta client build 1.60.1.69893 (Holy 18, Protection 16, Retribution 18). Featured allocations are community planning examples, and later client builds may change the underlying fields.

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm test
npm run build
```

Talent names and effects in this preview are marked as community reported. Classic comparisons are used as a secondary reference; the interface does not present demo values as final release data.
